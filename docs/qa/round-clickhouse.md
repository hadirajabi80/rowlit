# QA round: ClickHouse (server 24.8.14.39, docker `dbstudio-it-clickhouse-1`)

Method: real engine from the worktree + headless Edge driver (console, explorer, data tab, views) and a WebSocket query
runner against the sample server (`shop`, scratch database `qa_ch`, dropped afterwards). Fixes below were reproduced first.
Docker Desktop became unresponsive (HTTP 500 from the engine API) late in the round, so fixes made after that point are
verified by unit tests only; they are marked "unit" in the Verified column.

Checked and fine: connect-form validation messages (bad host, port, settings), read-only enforcement on the console and the
admin endpoints (403 READ_ONLY), cancel / row cap path (code reading), `USE db` persistence inside a session, script mode
error positions, parts / mutations / merges views and endpoints (failed mutation shows the reason, Kill works), completion of
engines / settings / formats / function case, formatter (PREWHERE / SETTINGS on their own lines, function case as is),
nested values in the grid (arrays, maps, tuples, Nullable, LowCardinality, Decimal128/256, Int256, UUID, IPv4/6, Enum, Date32,
DateTime64 before 1970).
