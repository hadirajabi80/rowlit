# Rowlit 1.6.0

## New: Linked databases
Query across several databases at once, without writing SQL if you prefer.
- **Links** — mount tables from several connections (SQL Server, PostgreSQL, MySQL/MariaDB, Oracle, SQLite,
  ClickHouse, Snowflake, Cassandra, plus MongoDB, Elasticsearch and CSV/Excel/JSON files) under short aliases, e.g.
  `crm.customers` from SQL Server and `shop.orders` from PostgreSQL. A link shows in the explorer under
  "Linked databases" like any other connection.
- **Visual query builder** — drag tables onto a canvas, drag a column onto another to join (inner/left/right/full/
  cross, with "ignore case" and "trim"), tick columns, add aggregates, calculated columns, filters, grouping, sorting
  and a limit; joins are suggested from foreign keys and names. The SQL is shown live; Advanced mode lets you edit it
  with IntelliSense and go back to the builder.
- **Federated engine** — an embedded DuckDB joins the data; only the columns and simple filters each query needs are
  read from each source. Large results spill to disk under a memory limit; cancel stops everything in under a second.
  Linked queries are always read-only.
- **Save as linked view**, export the results, **Materialize** them into a table on a writable connection (create,
  replace or append, with progress), see the **Plan** (what each source is asked for), and generate **native link**
  scripts (SQL Server linked server, postgres_fdw/mysql_fdw, Oracle database link, MySQL FEDERATED, ClickHouse)
  to run yourself.

## New
- **Memory and connection management** — Close connection / Close database in the explorer; idle sessions (15 min) and
  the least recently used connections beyond 20 are released automatically and reconnect transparently (database and
  schema restored); results of background tabs are released after 10 minutes (Reload brings them back); a memory
  indicator in the status bar with a Resources popover. Settings › Connections › Resources.
- **Customizable keyboard shortcuts** (F1) — record new shortcuts and chords, conflict warnings, presets for
  JetBrains/DataGrip, VS Code/Azure Data Studio and SSMS, import/export.
- **Schema switcher** in the console toolbar (PostgreSQL search_path, Snowflake USE SCHEMA; SQL Server shows the
  default schema and an editor schema for IntelliSense).
- **Import redesigned** — a step-by-step page with a clearer layout, paged preview, column mapping and a review step;
  **drop a file anywhere** in the window to import it (CSV/TSV/Excel/JSON), or a .sql file to open it.
- **Execute procedure dialog redesigned** — compact rows, typed inputs, validation, collapsible SQL preview; always
  fits the window.
- **Details panel in the Objects tab** — select an object to see what it uses and what uses it.
- **Stop the update download** from the status bar or Settings › Updates.

## Fixed
- Ctrl+click / F12 on a table in another schema loads that schema first, then opens it.
- Ctrl+click / F12 on a table or view opens its data; Alt+F12 opens the definition (DDL).
