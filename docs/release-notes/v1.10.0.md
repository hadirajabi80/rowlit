# Rowlit 1.10.0

## Connection folders in the explorer
Create a connection folder directly from the Explorer toolbar or its background context menu. Empty folders are saved
and also appear in the connection dialog's folder suggestions. Drag an existing server onto a folder to move it there,
including a collapsed folder, or drop it on the empty tree area to move it out. Moving a connection preserves its
settings and stored password.

## Saved row updates appear immediately
Fixed a grid display issue when updating a row that was inserted and saved during the same browsing session. The
database saved the update, but the grid could revert to the earlier value until refreshed. Saved inserts now display
subsequent updates and refetched trigger values immediately across the shared SQL data and result grids.

## Oracle schema discovery
Schema discovery now uses a portable ALL_USERS query without relying on ORACLE_MAINTAINED, which is unavailable on
older Oracle versions and can hide application schemas on newer installations. Known system accounts remain filtered
and the current schema remains available.

## Insert rows from the top toolbar
The shared SQL table and result toolbars now have a visible Insert row button. In result grids it stays available
when optional toolbar actions move into the overflow menu, so adding a row does not require scrolling to the bottom.
