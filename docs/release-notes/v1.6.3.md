# Rowlit 1.6.3

## New
- **Link whole databases** — a linked database can now mount a whole schema, a whole database (every schema) or a
  whole connection (every database), not only picked tables. Right-click a database or schema in the explorer and
  choose **Link database…** / **Link schema…**, or pick the scope per source in the link editor. Query nested tables
  as `crm.sales.orders` (whole database) or `crm.shop.dbo.orders` (whole connection); `crm.orders` keeps working for
  the default schema. Tables load only when a query, the builder or IntelliSense needs them, so large databases stay
  fast. MongoDB (every collection) and Elasticsearch (every index) work too. Existing links keep working.
- **MySQL / MariaDB table options** in the designer: ENGINE, charset, collation, ROW_FORMAT and the AUTO_INCREMENT start.
- **Data tab close**: Save and close / Discard / Cancel.

## Fixed
- **Exact big numbers** — decimals with more than 28 digits, NaN and integers beyond 64 bits are written exactly on
  every database (they were rejected, or silently rounded past the 28th digit).
- **SQL Server** — completion after `OUTPUT inserted.` / `deleted.` and for built-in table functions (`STRING_SPLIT`,
  `OPENJSON`, …); the designer drops and recreates indexes, keys and checks around a column type change; a mistyped
  database fails in about a second.
- **Snowflake** — completion inside `$$ … $$` SQL bodies and after `USE`; the formatter upper-cases keywords such as
  `SHOW TABLES` and `CLUSTER BY` without touching names.
- **ClickHouse** — dictionaries are offered after FROM, open their data sorted by key, and have Open data in the menu.
- **PostgreSQL** — `timetz` shows and edits like the server; extension functions sit in their own folder.
- **MySQL** — no EXPLAIN rewrite note in the messages; filters work under `NO_BACKSLASH_ESCAPES`.
- **Cassandra / SQLite** — big bigints keep their digits in the cell viewer; `{'k':true}` is no longer a parameter;
  `SELECT ?` column name; views keep their column list in the designer.
- **Redis** — values that are not valid UTF-8 save back byte-exact; saving a deleted or retyped string key warns
  instead of recreating it; JSON `null` documents; partial folder counts show "340+"; faster Test connection.
- **Kafka** — slow consumer start no longer ends a browse early; the cluster version appears later if it was slow;
  Avro produce warns about unknown fields.
- **Elasticsearch** — the import preview reads only the start of large files; the SQL cursor closes when you leave the
  tab; closing a running job's dialog asks whether to keep it running.
- **MongoDB** — wildcard (`$**`) indexes; `-0`; filters from long example values; a failed export leaves no partial file.
- **Linked databases** — EXPLAIN shows a readable plan; the builder's Advanced mode asks for parameter values; Add to
  link no longer creates a duplicate source; safer confirmations.
- **Find in database** — Enter while results are loading opens the first result.
- **Objects page** — Cancel / Retry while connecting.
- **Themes** — better search-highlight contrast in Darcula and Nord.
