# Rowlit 1.8.0

## Export and import connections
**File › Export connections…** saves the connections you choose — settings and SSH tunnel settings — to a
`.rowlit-connections.json` file to share with your team or move to another machine. Passwords are left out unless you
tick **Include passwords** and enter a passphrase; then passwords, SSH passwords and key passphrases are encrypted with
AES-256-GCM using a key derived from your passphrase (PBKDF2-SHA256). The passphrase is not stored and cannot be
recovered. **File › Import connections…** previews the file and lets you choose per connection: import as new, replace
the saved connection with the same name (its id and open tabs are kept), or skip. Enter the passphrase to bring the
passwords along, or import without it. Right-click a folder in the explorer to export just its connections. Key files
and SQLite paths are exported as typed; linked databases are not exported.

## Pin results and compare result sets
- **Pin a result** — every result tab has a pin button (palette "Pin result", **Ctrl+Alt+K**). A pinned result is a
  read-only copy of its rows that stays when the console runs again: run a query, pin it, change the query, run again,
  and the old result is still beside the new one.
- **Compare result sets** — **Compare with…** in the result toolbar compares a result with another result set of the run
  or any pinned result. Rows are matched by key columns (the primary key by default, otherwise whole rows) and shown in
  one grid: added rows green, removed red, a changed row as a before/after pair with the differing cells marked. Choose
  key columns, ignore case, trim text, differences only and search; export the differences as CSV or Markdown. Large
  comparisons (over 50,000 rows) run in the background without freezing the window, and notices explain truncated
  results, missing or repeated keys and one-sided columns.

## Value editors
The value viewer is now an editor. Open a cell with **Shift+Enter** (or View value) and press the pencil to edit JSON,
XML and text in a Monaco editor with highlighting, error markers and Format; **Apply** puts the value into the pending
changes like typing in the cell, and invalid JSON/XML is blocked on json/xml columns. Binary values open as an **image**
(PNG, JPEG, GIF, WebP, BMP, SVG — with pixel size and fit / actual size) or as a hex dump, and text stored in binary
columns reads as text. **Save** any cell to a file, or **load** a cell's value from a file (images and other binary data
into blob columns, text into text columns; up to 16 MB). The Data tab gets the value viewer too. The viewer and its
editor load on demand, so start-up gets lighter.

## Generate test data
Right-click a table and choose **Generate data…** (also in the Data tab toolbar and the palette) to fill it with realistic
test rows. Rowlit picks a generator for every column from its type, name and constraints — names, emails, phones,
cities, companies, dates, prices, booleans, values from a CHECK list or an enum, sequences that continue after the
highest id; identity and serial keys are left to the database. Foreign keys pick existing parent values, and unique
columns (and multi-column unique indexes) never repeat — if a column cannot supply enough distinct values you are told
before anything is written. Change any generator and its options, set the share of NULLs, and check a live preview of
the first 20 rows; the same seed always gives the same rows. Rows are written with the fast import loaders in one
transaction (a failure or Cancel leaves the table untouched) or per batch; delete the existing rows first if you like,
and skip-and-report rows the server rejects with a downloadable CSV. Works on SQL Server, PostgreSQL, MySQL, MariaDB,
SQLite, Oracle, ClickHouse and Snowflake.

## Data compare and sync
Compare the rows of two tables, in the same or different databases (PostgreSQL, SQL Server, MySQL/MariaDB, SQLite,
Oracle; ClickHouse and Snowflake as a source): right-click a table › **Compare data…**, **Database › Compare data…**, the
palette, or **Compare** after a data transfer. Rows are matched on the primary key or columns you choose; each side can
be filtered or replaced by a query; ignore columns, trim or ignore case, set number and time tolerances, treat empty
text as NULL. Both tables are read sorted by the key and compared in one pass. You get counts of equal, changed,
only-in-source and only-in-target rows and a grid that highlights changed cells. **Synchronize…** writes the INSERT /
UPDATE / DELETE script that makes the target like the source (or the reverse) for the kinds of rows you tick — copy it,
open it in a console, or apply it in one transaction after a confirmation.

## Column statistics

Choose **Column statistics…** from a table or result column to see NULL share, distinct count, ranges, numeric totals,
top values and a compact distribution. Table profiles run as cancellable server jobs, keep the current filter, work on
read-only connections, and automatically sample very large tables. Query results are profiled locally and clearly say
that the figures cover the loaded rows.

## Editor bookmarks

Mark important SQL lines with **Ctrl+K, Ctrl+K**, jump forward or backward, and open the Bookmarks workspace to move
between marked lines across consoles. Markers are numbered, follow edits, and persist with the restored workspace. The
JetBrains/DataGrip keymap also provides **F2** and **Shift+F2** navigation.

## Server monitor

Open **Server: Open monitor** (**Ctrl+Alt+M**) for PostgreSQL, SQL Server, MySQL/MariaDB, ClickHouse, Oracle, or
Snowflake to see live sessions, throughput, memory/cache, I/O and server metrics, database sizes, and the longest
running queries in one dashboard. Choose a 2-second to 1-minute refresh interval, pause collection, and follow compact
30-minute sparklines; polling stops while the tab is hidden. The monitor reuses Activity's guarded session-termination
flow on writable connections and explains unavailable or permission-restricted provider metrics instead of presenting
misleading zeroes.
