# Rowlit 1.8.0

## Export and import connections
**File › Export connections…** saves the connections you choose — settings and SSH tunnel settings — to a
`.rowlit-connections.json` file to share with your team or move to another machine. Passwords are left out unless you
tick **Include passwords** and enter a passphrase; then passwords, SSH passwords and key passphrases are encrypted with
AES-256-GCM using a key derived from your passphrase (PBKDF2-SHA256). The passphrase is not stored and cannot be
recovered. **File › Import connections…** previews the file and lets you choose per connection: import as new, replace
the saved connection with the same name (its id and open tabs are kept), or skip. Enter the passphrase to bring the
passwords along, or import without it. Right-click a folder in the explorer to export just its connections. Key files
and SQLite paths are exported as typed; linked databases are not exported.

## Pin results and compare result sets
- **Pin a result** — every result tab has a pin button (palette "Pin result", **Ctrl+Alt+K**). A pinned result is a
  read-only copy of its rows that stays when the console runs again: run a query, pin it, change the query, run again,
  and the old result is still beside the new one.
- **Compare result sets** — **Compare with…** in the result toolbar compares a result with another result set of the run
  or any pinned result. Rows are matched by key columns (the primary key by default, otherwise whole rows) and shown in
  one grid: added rows green, removed red, a changed row as a before/after pair with the differing cells marked. Choose
  key columns, ignore case, trim text, differences only and search; export the differences as CSV or Markdown. Large
  comparisons (over 50,000 rows) run in the background without freezing the window, and notices explain truncated
  results, missing or repeated keys and one-sided columns.

## Value editors
The value viewer is now an editor. Open a cell with **Shift+Enter** (or View value) and press the pencil to edit JSON,
XML and text in a Monaco editor with highlighting, error markers and Format; **Apply** puts the value into the pending
changes like typing in the cell, and invalid JSON/XML is blocked on json/xml columns. Binary values open as an **image**
(PNG, JPEG, GIF, WebP, BMP, SVG — with pixel size and fit / actual size) or as a hex dump, and text stored in binary
columns reads as text. **Save** any cell to a file, or **load** a cell's value from a file (images and other binary data
into blob columns, text into text columns; up to 16 MB). The Data tab gets the value viewer too. The viewer and its
editor load on demand, so start-up gets lighter.
