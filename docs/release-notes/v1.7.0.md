# Rowlit 1.7.0

## SSH tunnels
Connect through a bastion / jump host. Every connection dialog has a new **SSH tunnel** section: SSH host, port, user,
and a password or a private key file (OpenSSH or PEM, optional passphrase), plus keep-alives. **Test connection** checks
the whole chain and says which hop failed — the SSH server (unreachable, wrong login, changed host key) or the database
behind it. Everything goes through the tunnel: consoles, the explorer, data tabs, the designer, search, import,
Activity, logs and linked databases. A dropped SSH connection reconnects by itself; host keys are remembered on first
connect and a changed key is refused; SSH passwords and passphrases are stored encrypted with your other secrets.
Works with PostgreSQL, MySQL, MariaDB, SQL Server, Oracle (Basic), ClickHouse, Cassandra (one contact point), Redis
(standalone), MongoDB (`mongodb://` with one host) and Elasticsearch (one node). Kafka, Redis Cluster/Sentinel and
`mongodb+srv://` cannot use a tunnel, and Rowlit says why. PuTTY `.ppk` keys must be exported as OpenSSH first.

## Result charts
Turn any result into a chart: every result set and every table's Data tab has a **Grid | Chart | split** switch in its
toolbar. Nine chart kinds — bar, horizontal bar, stacked bar, line, area, scatter, pie, donut and a single KPI number —
with X / Y / series, aggregation (sum, average, count, min, max), date bucketing, Top N, sorting, labels, legend and log
scale. Rowlit suggests a chart from your columns (a date with a number opens as a line chart), follows rows as they
stream in, and remembers the settings per query. Export as PNG or SVG or copy the image; "Toggle chart view of the
results" and "Export chart…" are in the command palette. Series colours are tuned for contrast in every theme. The chart
code loads only when you first open a chart.

## Local history of editors
Every console keeps a private timeline of its text, like DataGrip's Local History. A snapshot is taken when you run,
save or close an editor, when a file or saved query is opened, and every two minutes while you type (only if the text
changed). Press **Ctrl+Alt+H** (or Edit › Local history…, the tab or editor context menu, or the command palette) to see
the snapshots newest first, compare any of them with the editor text, and restore, copy, label or delete it. Restoring
keeps the text it replaced, so it can always be undone. A console later saved to a file or a saved query keeps its
earlier history, and history survives restarts. Snapshots are stored compressed on this computer only: up to 200 per
editor, kept 30 days (Settings › Editor › "Keep local history", 1–365 days) and 20 MB in total; labelled snapshots are
never removed automatically.
