# Rowlit 1.6.1

A quality release: every database, the design, the everyday workflows and every feature were tested against real
servers, and about 170 problems were fixed. Reports are in `docs/qa/round-*.md`.

## Fixed
- **Close connection / Close database** now works with consoles and Data tabs open: nothing reconnects by itself
  afterwards. Open Data tabs keep their rows under a "Disconnected — Reconnect" banner, the console shows a Reconnect
  button, and unsaved grid edits ask Save / Discard / Cancel first.
- **SQL Server** — console results from a single table are editable; `USE other` is followed by the toolbar and
  IntelliSense; completion of data types in `CAST`/`CONVERT`, table hints in `WITH (…)` and columns after `TOP n`;
  faster, clearer Test connection errors; clear messages when a log query times out or SQL Agent is not running.
- **Oracle** — the script splitter handles `END CASE`, local subprograms, labelled blocks and `WITH FUNCTION`; errors in
  anonymous blocks point to the right line; object/VARRAY columns, `TIMESTAMP(9)` nanoseconds and 23ai `VECTOR`
  values display correctly.
- **PostgreSQL** — arrays with NULLs, large/NaN numerics, `inet`, ranges, infinite and BC dates, `24:00` and records
  show exactly like PostgreSQL; types created in the session are readable at once; DDL for partitions, inheritance
  and `WITH NO DATA` views; partitioned table sizes; triggers with the same name on several tables.
- **MySQL / MariaDB** — BIT and long/negative TIME values can be edited; TIME above 24 h displays correctly; MariaDB no
  longer repeats an old error after later statements; the designer's identity checkbox reflects AUTO_INCREMENT.
- **SQLite** — tables without a primary key (including every imported table) are editable via `rowid`; editing a
  view keeps its triggers; table rebuilds work with views on views, renames together with column changes, and
  case-only renames; import into attached databases.
- **ClickHouse** — saving grid edits works (mutations); `… FORMAT JSON` in the console; nested Date/DateTime values;
  the designer keeps engine arguments and multi-column keys; log level filters; drop for dictionaries, materialized
  views and functions.
- **Snowflake** — key-pair passphrases (and other extra password fields for every database) now reach the engine;
  values with `;` in connection options; `//` comments; mixed-case database and schema names; QUALIFY, FLATTEN and
  stage references in IntelliSense and the formatter.
- **Cassandra** — mixed-case and reserved column names are quoted; grid filters only send what CQL accepts and apply the
  rest locally; export of filtered data; inserts with TTL; clearer connection errors.
- **Redis** — editing then deleting a hash/zset row; removing the exact list element clicked; binary key names;
  Test connection rejects a wrong ACL user; Run executes the current line.
- **MongoDB** — field order is preserved on edit; Extended JSON `$timestamp`/`$date`; regex round-trip; stricter CSV
  type detection (zip codes, phone numbers); paging after a new filter; partial array inserts are reported.
- **Kafka** — looking up a misspelled topic no longer creates it; Pretty JSON keeps big numbers exact; produce
  tombstones; correct newest-first order; Avro errors name the field.
- **Elasticsearch / OpenSearch** — create-index settings; CSV export includes all fields; big integers stay exact in
  import and in the document editor; date-math and cross-cluster paths in Dev Tools; Cancel for slow requests.
- **Linked databases** — empty MongoDB collections; Oracle Append; decimals keep their scale; "matches regex" filters;
  quoted names in native FDW scripts.
- **Everyday use** — Ctrl+P and the explorer list overloaded functions once; "Did you mean …?" for PostgreSQL, MySQL,
  ClickHouse and Snowflake errors; hints when Test connection fails; Esc in the import wizard no longer discards the
  setup; "Sort by this column" in the cell menu; "Restart to update" warns about unsaved edits; confirmations raised
  from another dialog appear on top.
- **Design** — better contrast in Find, badges, pills and Nord highlights; the Objects tab and the linked query builder
  fit narrow windows; tidier error hints in a narrow results pane.
