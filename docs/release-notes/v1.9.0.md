# Rowlit 1.9.0

## Explicit schema nodes in the explorer
Oracle connections now show their schemas (SHOP, HR, …) as their own level in the database explorer: expanding the
connection lists its schemas, and a schema's objects load only when it is expanded. SQL Server databases do the same —
every database shows its schema nodes (dbo, Sales, …) even when the database has just one schema, like SSMS. Objects
always sit beneath the schema that owns them, so two schemas can hold identically named tables without colliding, and
SQLite keeps its flattened single "main" schema as before.

## All SQL Server schemas listed
The schema list of a SQL Server database now returns every schema the server reports — dbo and the user schemas
alongside sys, INFORMATION_SCHEMA, guest and role-owned schemas such as db_owner — each with its object count, instead
of hiding the built-ins and empty schemas. System schemas can show zero application objects, because object listings
still exclude Microsoft-shipped objects.

## Security
Updated MySqlConnector to 2.6.2 to clear a moderate-severity advisory (GHSA-473q-m89c-ghf8) reported by the NuGet audit.
