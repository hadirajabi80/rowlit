# Rowlit 1.6.2

## Fixed
- **No more silent data loss on quit** — closing the window or quitting (Ctrl+Q, the window X, Cmd+Q, the Dock)
  now asks first when something would be lost, and says what: unsaved grid edits and open transactions per
  connection. Cancel keeps everything open and connected; a window that does not answer never blocks quitting.
  Closing a detached window only asks about its own work.
- **Dead connections no longer hang** — when a server went away (a restart, a dropped VPN, a sleeping laptop) the
  explorer could show "Connecting…" and a Data tab "Loading…" for minutes. Rowlit now detects the broken connection,
  reconnects once by itself, and otherwise shows "Server not reachable" with Retry. Loads that take longer than 15 s
  show "Still connecting…" with Cancel.
- **JetBrains keymap** — Ctrl+B in the editor opens the definition (Alt+F12 still works); elsewhere it toggles the side
  panel as before.
