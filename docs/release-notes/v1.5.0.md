# Rowlit 1.5.0

## New
- **Import Wizard** — import CSV/TSV, Excel (.xlsx) and JSON/NDJSON into a new or an existing table: live preview,
  delimiter/encoding detection (UTF-8, UTF-16, Windows-1256 for Persian), column mapping, type inference and a
  CREATE TABLE preview; append, truncate, upsert or update-only; fast bulk loading (SqlBulkCopy, COPY, ClickHouse bulk
  insert, Oracle array binding); progress, cancel, skip bad rows and an error report. Right-click a table or schema,
  use the data tab's Import button, or drop a file on the explorer.
- **Export like Navicat** — "Export data…" with a choice of scope: the loaded rows, the selection, every row matching
  the current filter and sort, or all records (with counts); for query results also "re-run and export all rows".
  CSV, TSV, Excel, JSON, SQL INSERT and Markdown, UTF-8 with BOM for Excel, progress and cancel for large exports.
- **Types like SSMS** — SQL Server Types grouped into User-Defined Data Types, Table Types, CLR Types and XML Schema
  Collections, plus System Data Types; PostgreSQL enums, domains, composite and range types; Oracle object, VARRAY and
  nested table types. Overview, columns, indexes, "Used by", Script as CREATE, Drop and New type.
- **Schema and database colours** — right-click › Set colour…; shown in the explorer, on tabs and in the switcher.
- **Movable results pane** — dock results/messages at the bottom, right or left, close it, or open them in their own
  tab. Procedure edit consoles start with the pane closed and show save messages as a toast.
- **Ctrl+S in a query saves it to a schema** (consoles opened from a .sql file still save to the file).
- **Cross-database IntelliSense on SQL Server** — `OtherDb.dbo.Table`, `alias.` columns, hover, F12 and `USE OtherDb`.
- **853 built-in snippets** across all eight SQL dialects (Ctrl+J), grouped into Query, DML, DDL, Programmability and
  DBA, tested against real servers.
- **JetBrains-style themes** — Darcula, JetBrains Dark/Light (New UI), IntelliJ Light and High Contrast code themes,
  Darcula and IntelliJ Light app themes, and VS Code Dark+/Light+, Tokyo Night, Catppuccin, Gruvbox, Ayu, Night Owl,
  Material and Rosé Pine.

## Fixed
- Clicking a table always opens its data — from the explorer, the Objects tab, Find in database, Ctrl+P, Dependencies
  and the ER diagram (it used to open the structure tab from some of them).
- Tables no longer fail to open after about eight data tabs (the per-connection session limit now frees idle tabs).
- Oracle tables with object-type columns open (those cells show a placeholder).
- Tables whose names differ only in case, or contain dots, get their own tabs; reopening a tab keeps its filter.
- A table that cannot be read shows a clear error instead of nothing.
