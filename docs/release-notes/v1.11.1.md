# Rowlit 1.11.1

## Table tools that fit
The table data toolbar stays on one line without horizontal scrolling. Insert row and search remain available;
secondary actions move into the More table actions menu as the pane narrows. Filter, export, chart, save, import,
design and viewer actions remain accessible in narrow panes.

## Reliable connection cleanup
Disconnect all in the memory inspector now uses the engine's resource list even when this window has no cached
sessions or catalog. Close buttons show progress and distinguish released connections from open ones.

Closing a database or connection stops automatic paging, queued counts and unfinished describe/page work from
reopening it. Loaded rows remain available, and an explicit reconnect, refresh or Load more opens it again.

The engine waits for idle health checks before releasing a connection and reports an error when busy sessions
cannot stop, instead of reporting a successful close while a connection is still open.
