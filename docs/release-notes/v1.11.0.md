# Rowlit 1.11.0

## A memory inspector, one click away
Click the memory reading at the bottom of the app to open the new Memory & resources inspector. See live usage against
your memory limit, expand engine and app/window details, and inspect managed heap, renderer/process usage, result and
metadata caches, and the resources held by each connection. Readings refresh every five seconds while the panel is open.

The inspector now renders outside the status bar, fixing the clipped panel that could make clicking the memory reading
appear to do nothing. The panel stays within the viewport, supports scrolling and keyboard dismissal, and returns focus
to the status-bar control when closed.

## Free memory now
The prominent cleanup button releases eligible background result rows and unused window catalogs, runs engine cleanup
and compacts its managed heap immediately. Explicit cleanup works even when automatic release is off and bypasses the
automatic garbage-collection cooldown. Running queries, visible results, unsaved edits, open transactions and temporary
objects retain their protections.

Cleanup shows progress, prevents duplicate requests and samples usage again afterward. The panel reports the measured
before/after memory and freed background rows; when there is no measurable drop, it says so. A failed cleanup can be
retried without closing the inspector.
